# Tic Tac Toe Game

A simple web-based Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two player game
- Winner detection
- Restart button

## How to Run
1. Download or clone the repository
2. Open index.html in browser

## Technologies Used
- HTML
- CSS
- JavaScript
